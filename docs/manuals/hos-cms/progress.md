# ความคืบหน้าคู่มือ HOS-CMS

อัปเดต: 26 พฤศจิกายน 2569 — ตรวจทานอิสระและจัดทำฉบับปรับปรุง

## ผลการตรวจทานรอบนี้

- ตรวจต้นฉบับ 16 บท, `manual.md`, ภาพทั้ง 71 ไฟล์ในแผ่นรวมภาพ, เอกสารวิเคราะห์/สารบัญ/แผนเดินหน้าจอ และเทียบจุดสำคัญกับโค้ดปัจจุบัน
- แก้ขั้นตอนกำหนดสิทธิ์หน้าในบท 6 และผลหลังเปลี่ยนรหัสผ่านในบท 1; ตัดบันทึกทางเทคนิคที่ไม่จำเป็นสำหรับผู้ใช้จากต้นฉบับรายบท แล้วรวม `manual.md` ใหม่
- สร้าง `manual-hos-cms-final.docx` โดยเก็บ `manual-hos-cms.docx` เดิมไว้; ตรวจโครงสร้างได้ 16 บทและภาพฝัง 71 ภาพ ไม่มีลิงก์ภาพขาด
- รายการปัญหา หลักฐาน การแก้ไข และข้อจำกัดอยู่ใน `review-report.md`
- **ยังไม่รับรองการจัดหน้า DOCX ใหม่:** การ render ด้วย LibreOffice ไม่ได้ไฟล์ PDF ชั่วคราว และไม่สามารถเปิดไฟล์ผ่าน Word UI เพื่อดูหน้ากระดาษได้ จึงยังไม่ยืนยันเลขหน้า สารบัญภาพ การตัดหน้า และความอ่านได้ของภาพขนาดพิมพ์

สถานะส่งมอบรอบนี้: เนื้อหาและโครงสร้างปรับปรุงแล้ว; การตรวจจัดหน้าจริงยังค้างตามรายงานตรวจทาน

## ผลการจัดทำ Word

- ไฟล์ส่งมอบ: `manual-hos-cms.docx` เปิดใน Microsoft Word ได้จริง จำนวน **100 หน้า** ตามสถานะที่ Word แสดง
- เนื้อหา **16 บท**, ภาพฝัง **71 ภาพ**, คำบรรยายแบบ Word Caption **71 รายการ**; สารบัญหัวข้อและสารบัญภาพเป็น Word fields ที่ปรับปรุงรายการและเลขหน้าแล้ว
- กระดาษ A4 แนวตั้ง ขอบทั้งสี่ด้าน 2.54 ซม.; Styles ใช้เนื้อหา 16 pt, Heading 1 ขนาด 20 pt, Heading 2 ขนาด 18 pt, Caption ขนาด 14 pt; สีประกอบเขียวอมฟ้า
- ตรวจเปิดเอกสารใน Microsoft Word: ตัวอักษรไทยแสดงครบ, หัวข้อและเลขหน้าปรากฏ, ตาราง Page Builder มีหัวตารางต่อหน้า, ภาพและคำบรรยายอยู่ในลำดับที่กำหนด; ตรวจโครงสร้าง DOCX ว่า ZIP/XML เปิดได้และไม่มีภาพขาด
- ฟอนต์ **TH Sarabun New** ไม่พบในเครื่อง จึงใช้ **Sarabun** ที่ติดตั้งอยู่และ Word แสดงภาษาไทยได้ถูกต้อง
- ข้อจำกัดการตรวจ: LibreOffice บนเครื่องนี้ Render อักษรไทยเป็นช่องว่างใน PDF ชั่วคราว แม้ Word แสดงครบ จึงใช้ Microsoft Word ตรวจการแสดงผลภาษาไทยและจำนวนหน้าเป็นหลัก; ไม่ได้สร้าง PDF ฉบับส่งมอบ

ขั้นต่อไป: รอคำสั่งสำหรับ PDF หรือการปรับแก้คู่มือรอบถัดไป
