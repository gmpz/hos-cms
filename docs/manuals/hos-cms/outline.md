# สารบัญและแผนคู่มือ HOS-CMS (ฉบับเสนออนุมัติ)

ผู้อ่าน: เจ้าหน้าที่โรงพยาบาลและผู้ดูแลเว็บไซต์ที่ไม่เขียนโปรแกรม ภาษาหลัก: ไทย ตัวอย่างใช้ Local Development Server และข้อมูลที่ไม่เป็นความลับ

## สารบัญที่เสนอ

1. **เริ่มใช้งานระบบ** — จุดประสงค์ของ Public/CMS, วิธีเข้าเว็บไซต์, Login, OTP เมื่อบัญชีเปิดใช้, เปลี่ยนรหัสผ่านครั้งแรก, ออกจากระบบ
2. **รู้จักหน้าเว็บไซต์ประชาชน** — หน้าต้อนรับ/หน้าแรก, เมนูหลักและเมนูย่อย, ข่าวและผลงาน, หน่วยงาน, เอกสาร, ค้นหาทั้งเว็บไซต์, หน้าองค์กร/บริการเจ้าหน้าที่, ส่วนท้ายและนโยบาย
3. **บัญชีและความปลอดภัยของฉัน** — เมนูบัญชี, แก้โปรไฟล์และรูป, เปลี่ยนรหัสผ่าน, OTP, รหัสกู้บัญชี (ตัวอย่างปิดบัง), ออกจากอุปกรณ์อื่น
4. **ภาพรวมผู้ดูแล** — Dashboard, ตัวเลขเนื้อหา/ผู้เข้าชม, กิจกรรมล่าสุด, ทางลัด, รายงานผู้เข้าชม
5. **คลังสื่อ** — อัปโหลดรูป/ไฟล์, ค้นหาและกรอง, เปลี่ยนมุมมอง, เลือกสื่อจากตัวแก้ไข, ข้อควรระวังไฟล์และข้อมูลส่วนบุคคล
6. **หน้าเว็บไซต์และ Page Builder** — รายการ/ค้นหา/สถานะ/ถังขยะ, สร้างหน้า, ชื่อและเส้นทาง, แก้หน้าแรก, ตั้งค่าหน้า, เพิ่ม/จัดลำดับ/ทำสำเนา/ซ่อนบล็อก, ตัวอย่าง, ร่าง/เผยแพร่, สิทธิ์เข้าถึง, กลุ่มบล็อกข้อความ/สื่อ/ลิงก์/ข้อมูล/ฝังภายนอก
7. **เมนูนำทางเว็บไซต์** — เพิ่มเมนูหลักและย่อย, เลือกปลายทาง, เปลี่ยนลำดับ, ซ่อน/แสดง, ตรวจตัวอย่าง, เผยแพร่
8. **หน้าต้อนรับและประกาศเมื่อเข้าเว็บ** — จัดการหน้าต้อนรับ, ข้อความ/ภาพและความถี่; จัดการประกาศ, ลิงก์และความถี่; ร่าง/เผยแพร่/ถังขยะ
9. **ข่าวและผลงาน** — รายการ/ค้นหา/กรอง, สร้างแบบฟอร์ม, สร้างแบบบล็อก, หมวด/เจ้าของ/รูปปก, ตัวอย่างหลายขนาด, ร่าง/เผยแพร่/ยกเลิกเผยแพร่, คัดลอก/ถังขยะ
10. **หมวดหมู่ข่าวและเอกสาร** — สลับสองแท็บ, เพิ่ม, เปลี่ยนชื่อ, จัดลำดับ, ปิด/เปิดใช้งาน, ลบ และผลต่อการกรอง
11. **หน่วยงานและหน้าหน่วยงาน** — รายการ/สถานะ, สร้าง, ข้อมูลทั่วไปและติดต่อ, เนื้อหา, เมนูบริการแบบกลุ่ม, บุคลากร, การจัดหน้า, สิทธิ์, ร่าง/เผยแพร่/ถังขยะ
12. **เอกสารเผยแพร่** — ค้นหา/กรองหมวด/ปีงบประมาณ/สถานะ, เพิ่ม/แก้ไขข้อมูลและไฟล์, เจ้าของเอกสาร, ร่าง/เผยแพร่/เก็บถาวร, ถังขยะ
13. **บัญชีบุคลากรและข้อมูลบุคลากร** — รายการ/ค้นหา/สถานะ, เพิ่ม/แก้ไขผู้ใช้และบทบาท, นำเข้าจาก Excel, รีเซ็ตรหัสผ่าน/OTP, session; ประเภทบุคลากร/ตำแหน่ง/ระดับ
14. **ตั้งค่าข้อมูลโรงพยาบาลและรูปลักษณ์** — ข้อมูลทั่วไป, ช่องทางติดต่อ/โซเชียล/แผนที่, ธีม/โลโก้และตัวอย่าง
15. **ติดตามและดูแลระบบ** — บันทึกกิจกรรม, กรอง/ค้นหา/รายละเอียด, ตรวจผลหลังเผยแพร่และการแก้ปัญหาเบื้องต้นตามข้อความที่ระบบแสดง
16. **ภาคผนวก** — ความหมายร่าง/เผยแพร่/ถังขยะ, ตารางสิทธิ์ ADMIN/MEMBER/Public, ชนิดบล็อกทั้งหมด, คำศัพท์หน้าจอ, แนวทางใช้ภาพจริงและคุ้มครองข้อมูลลับด้านความปลอดภัย

## แผนภาพหน้าจอ

| บท | ภาพโดยประมาณ | จุดจับภาพที่วางแผน |
|---|---:|---|
| 1–3 | 16–20 | Login, OTP แบบไม่เผยรหัส, เมนู Public, ค้นหา/กรอง, โปรไฟล์และความปลอดภัย |
| 4–5 | 8–11 | Dashboard, รายงานผู้เข้าชม, คลังสื่อสองมุมมองและตัวเลือกสื่อ |
| 6 | 18–24 | รายการหน้า, สร้างหน้า, Page Builder, ตั้งค่าบล็อกตามกลุ่ม, สิทธิ์, ตัวอย่าง |
| 7–8 | 12–16 | ผังเมนูหลัก/ย่อย, หน้าต้อนรับและประกาศในสถานะต่าง ๆ |
| 9–10 | 12–16 | รายการข่าว, ตัวแก้ไขสองแบบ, ตัวอย่าง, หมวดข่าว/เอกสาร |
| 11–12 | 14–19 | แท็บหน่วยงาน 5 ส่วน, รายการ/ตัวแก้ไขเอกสารและตัวกรอง |
| 13–15 | 13–18 | บัญชี/นำเข้า, ข้อมูลบุคลากร, ตั้งค่า, ธีม, กิจกรรม |
| 16 | 2–4 | ตารางสิทธิ์และชนิดบล็อก (ใช้ภาพเฉพาะที่ช่วยอธิบาย) |
| **รวม** | **95–128** | ภาพจริงหลังอนุมัติ; ข้อกำหนดล่าสุดให้แสดงข้อมูลทดสอบทั่วไป และปิดบังเฉพาะความลับด้านความปลอดภัย |

คาด **16 บท, ประมาณ 100–145 หน้า** เมื่อใช้คำอธิบายทีละขั้นและภาพ 1–2 ภาพต่อหน้า ขนาดจริงขึ้นกับความยาวข้อมูลบนหน้าจอและการแบ่งเล่ม แนะนำแบ่งผลส่งเป็น 3 ส่วนอ่านง่าย: เจ้าหน้าที่ทั่วไป (บท 1–3), จัดการเนื้อหา (บท 4–12), ดูแลระบบ (บท 13–16) โดยสารบัญนี้ยังคงเป็นแผนรวมเดียว

## ขั้นตอนเมื่ออนุมัติ

1. ทวนเมนู/ข้อมูลจริงและกำหนดตัวอย่างที่ไม่มีข้อมูลลับ รวมถึงบัญชีสำหรับบทบาทที่ต้องตรวจเพิ่ม
2. จัดทำ walkthrough แยกหัวข้อ ใช้ Session ที่ได้รับอนุญาต และหยุดก่อนปุ่มเปลี่ยนข้อมูลทุกครั้ง เว้นแต่มีอนุญาตเฉพาะขั้นตอนในสภาพแวดล้อมทดสอบ
3. จับภาพจริง ตรวจทุกภาพ แสดงข้อมูลทดสอบทั่วไป และไม่ให้รหัสผ่าน Token OTP หรือรหัสกู้บัญชีปรากฏ
4. เขียน Markdown ภาษาไทยและให้ตรวจเนื้อหา ก่อนจัดรูป Word/PDF ในขั้นต่อไป

ยังไม่ได้จับภาพ สร้าง walkthrough, Word หรือ PDF ในรอบการวิเคราะห์นี้

> ผลจริงหลังจัดทำ: 16 บท ภาพ 71 ภาพ รายละเอียดอยู่ใน `progress.md` และ `manual.md`
