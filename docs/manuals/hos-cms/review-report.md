# รายงานตรวจทานคู่มือ HOS-CMS

วันที่ตรวจ: 26 พฤศจิกายน 2569

## ขอบเขตและวิธีตรวจ

ตรวจ `system-analysis.md`, `outline.md`, `progress.md`, `walkthrough.json`, ต้นฉบับ 16 บท, `manual.md`, DOCX เดิม และภาพ PNG ทั้ง 71 ภาพ เทียบข้อความสำคัญกับโค้ดปัจจุบัน โดยเน้น Page Builder สิทธิ์หน้า และการจัดการบัญชี ตรวจภาพทุกไฟล์ในแผ่นรวมภาพหกแผ่น ตรวจไฟล์อ้างอิงและโครงสร้าง DOCX ด้วยโปรแกรม ไม่ได้กดคำสั่งที่เปลี่ยนข้อมูลระบบ

## ผลตรวจภาพและเอกสาร

- ภาพ PNG ทั้ง 71 ไฟล์เปิดอ่านได้และแผ่นรวมภาพแสดงเนื้อหาตรงกลุ่มบท; ไม่มีภาพว่างหรือภาพผิดหน้าที่เห็นชัดในระดับภาพรวม ไม่มีการจับภาพใหม่
- ตรวจลำดับภาพใน `manual.md`: อ้างอิง 71 รายการ ไม่มีไฟล์ภาพขาด; DOCX ใหม่มี drawing และไฟล์ media อย่างละ 71 รายการ
- ภาพหน้าจอมีข้อความเล็กโดยเฉพาะภาพแผงตั้งค่าบล็อก 14 ภาพ ภาพต้นฉบับไม่เล็กกว่า 600 × 350 พิกเซล แต่ยังไม่ได้ยืนยันความอ่านได้เมื่อพิมพ์จริง
- ตรวจภาพรวมไม่พบรหัสผ่าน QR สำหรับ OTP หรือรหัสกู้บัญชีที่มองเห็นได้ การตรวจระดับพิกเซล/อ่านข้อความทุกส่วนของภาพยังไม่สมบูรณ์
- ต้นฉบับ 16 บทและ `manual.md` ตรงกันหลังรวมเล่ม; DOCX ใหม่เป็น ZIP/XML ที่ตรวจความสมบูรณ์ได้ ไฟล์เดิม `manual-hos-cms.docx` ยังอยู่สำหรับเปรียบเทียบ

## ประเด็นที่ยังยืนยันไม่ได้

1. ผลจริงหลังบันทึก เผยแพร่ ลบ กู้คืน นำเข้าบัญชี และเปลี่ยนสิทธิ์ ไม่ได้ทดลองเพื่อหลีกเลี่ยงการเปลี่ยนฐานข้อมูล จึงยืนยันจากโค้ดและหน้าจอที่มีอยู่เท่านั้น
2. พฤติกรรมทุกเส้นทางของบัญชี `MEMBER`, หน้าแบบกำหนดผู้มีสิทธิ์, OTP และรหัสกู้บัญชี ยังไม่ได้ทดสอบแบบครบลำดับ
3. การจัดหน้าจริงของ `manual-hos-cms-final.docx` ยังตรวจไม่ผ่านขั้นตอน render: LibreOffice ไม่สร้าง PDF ชั่วคราว และ Word ไม่เปิดไฟล์ผ่านเครื่องมือควบคุมหน้าจอในรอบนี้ จึงยังยืนยันเลขหน้า สารบัญภาพ การตัดหน้า ภาพล้น และฟอนต์ไทยในฉบับใหม่ไม่ได้
4. ภาพต้นฉบับบางภาพมีรายละเอียดผู้ใช้และเนื้อหาทดสอบทั่วไป ซึ่งผู้ว่าจ้างระบุว่าไม่ต้องปิดบัง; ยังต้องตรวจภาพต้นฉบับเต็มขนาดอีกครั้งก่อนส่งภายนอกหากข้อกำหนดด้านข้อมูลของหน่วยงานเปลี่ยน

## ผลตรวจหลังปรับปรุง

ผ่านการตรวจโครงสร้าง: 16 บท, 71 ภาพ, ลิงก์ภาพครบ, DOCX ใหม่ไม่เสียหาย และเลขคำบรรยายภาพใน DOCX ไม่ซ้ำซ้อน **ยังไม่ผ่านการรับรองด้านการจัดหน้า Word และการใช้งานหลังคำสั่งเปลี่ยนข้อมูล** ตามประเด็นค้างข้างต้น
